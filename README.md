One original, funny text message someone sends to their fridge at 3AM — a polite negotiation with an appliance that hums all night and judges silently. Running `main.py` writes the text to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` if unset) and prints it to stdout.

## Run it

```sh
python3 main.py
```
